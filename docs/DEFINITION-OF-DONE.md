# Definition of Done

A feature is done when:

## Functionality

- [ ] User flow works
- [ ] Validation works
- [ ] Error handling works
- [ ] Loading state works
- [ ] Empty state works

## Architecture

- [ ] Correct feature directory
- [ ] No duplicated reusable components
- [ ] Page remains thin
- [ ] Data access is separated from UI
- [ ] Configuration is not hardcoded

## UI

- [ ] Matches design system
- [ ] Responsive
- [ ] Dark mode works
- [ ] Focus states work
- [ ] Keyboard navigation works

## Code Quality

- [ ] TypeScript passes
- [ ] ESLint passes
- [ ] Tests pass
- [ ] No unnecessary dependencies
- [ ] No unrelated refactors

## Documentation

- [ ] Public reusable APIs documented when needed
- [ ] Architecture docs updated when behavior changes
