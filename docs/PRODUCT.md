# Product Specification

## Product
Multi-Purpose Next.js Admin Template.

## Target Users
- SaaS developers
- Freelancers
- Agencies
- Startup teams
- Internal-tool developers
- Developers building CRM/e-commerce/admin applications

## Core Value
Provide a polished admin foundation that can be adapted to many products without rewriting the layout, design system, tables, forms, navigation, theme system, and common business UI.

## Primary Modules
- Dashboard
- Users
- Products
- Orders
- Projects
- Billing
- Messages
- Notifications
- Settings
- Authentication
- RBAC

## Reference Dashboards
1. SaaS
2. E-commerce
3. Analytics
4. CRM
5. Project Management
6. Finance

## UX Requirements
- Fast navigation
- Responsive sidebar
- Command palette
- Search
- Breadcrumbs
- Consistent page headers
- Data tables
- Filters
- Bulk actions
- Forms
- Charts
- Toasts
- Empty states
- Skeleton loading
- Error states
- Dark/light/system themes
